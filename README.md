# StrayHelp

A full-stack community platform for reporting, rescuing, and rehoming stray animals.
Users can post stray sightings or pets needing a new home, browse listings by city and type, and connect directly with posters - with an admin dashboard for moderation.
A scalable full-stack application featuring a clean user interface and a robust backend, aimed at creating a community-driven platform where users can report, rescue, adopt, sponsor, and support stray animals in need.

## Tech Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Spring Boot, Spring Security (JWT)
- Database: PostgreSQL
- Image Storage: Cloudinary
